## 什么是 AiPy？
AiPy（爱派）是由**北京知道创宇（Knownsec）**研发的开源 AI 桌面助手，核心理念是 **Python-Use**：
把自然语言直接翻译成 Python 代码并执行，让 AI 真正「操作你的电脑」，而不是只聊天。
- 官网：https://www.aipyaipy.com
- 特点：本地执行、代码即代理、支持 MCP/Skills、跨平台（macOS / Windows / Linux）
---
## 场景
某 3C 家电全国连锁品牌的销售负责人，需要分析各门店销售情况汇总数据。
**痛点**：
- **海量数据无从下手**：2800+ 订单，人工统计耗时耗力易出错
- **多维度分析需求**：总体业绩 + 产品分布 + 门店排名 + 顾客画像 + 促销效果
- **异常订单排查**：促销活动中疑似薅羊毛，需快速定位
- **决策支持缺失**：需要基于数据给出销售策略优化建议
**目标**：基于一份销售明细表，输出一份包含多维度分析的 HTML 报告。
---
## 操作步骤
1. 打开 AiPy，在集市安装 skill：**EXCEL可视化分析**、**网页前端开发**
2. 上传销售数据表格，输入提示词（见下方「提示词」）
3. AiPy 自动读取数据、编写分析脚本、生成报告
### 提示词
```text
我是一家3C家电全国连锁品牌的销售负责人，请帮我分析这份各门店销售情况汇总数据。
1、文件路径：（此处请上传表格文件）
2、文件内容：表头分别为：order_id、date、product_category、product_name、brand、unit_price、quantity、total_amount、payment_method、customer_gender、customer_age_group、promotion、store_location、sales_time、salesperson
3、分析内容：编写一份HTML门店销售分析报告，包括总销售额、产品销售分布、促销情况、门店销售排名、顾客画像、销售员情况、是否存在薅羊毛的情况、对未来的销售策略调整的优化建议等。
4、分析规则：分析前，请先读取前30行，了解数据格式，然后根据具体数据格式编写合适的分析脚本进行分析。
5、报告保存到当前工作目录。
```
## AiPy 实现过程
| 步骤 | 环节 | 说明 |
|------|------|------|
| 1 | 自动获取数据 | 智能抓取销售数据原始表 |
| 2 | 数据清洗整理 | 自动处理缺失值、统一数据格式 |
| 3 | 多维度深度分析 | 销售趋势、客户画像、门店排名 |
| 4 | 生成专业图表 | 趋势图、对比图、占比图自动绘制 |
| 5 | 撰写深度报告 | HTML + PPT + Word 三种格式输出 |
**技术栈**：Python、Pandas、Matplotlib、HTML/CSS

## 常见问题（FAQ）
**Q1：AiPy 需要联网吗？**
A：不需要。AiPy 支持纯本地运行，销售数据不上传云端，数据安全有保障。
**Q2：需要会编程吗？**
A：不需要。上传表格并描述分析需求即可，AiPy 会自动生成并执行分析代码。
**Q3：AiPy 支持哪些操作系统？**
A：支持 macOS / Windows / Linux 桌面端。
**Q4：支持多大的数据量？**
A：本案例处理了 2800+ 订单，数据量可根据机器性能扩展。
**Q5：报告可以导出哪些格式？**
A：支持 HTML、Word、PPT 三种格式，分别适合在线查看、打印归档和开会汇报。
