# AiPy 实战：一句话生成四羊方尊冰箱贴文创提案（4 种风格 + F1–F10 特征约束）
> 上传一张博物馆实拍照片，让 AiPy 核对文物档案、提炼特征约束、生成 4 种风格 AI 效果图，输出一份可交付的 HTML 文创提案。
**关键词**：AiPy、文创提案、四羊方尊、冰箱贴、博物馆文创、AI 设计、平面与设计、网页前端开发、合规授权、自然语言编程
---
## 什么是 AiPy？
AiPy（爱派）是由**北京知道创宇（Knownsec）**研发的开源 AI 桌面助手，核心理念是 **Python-Use**：
把自然语言直接翻译成 Python 代码并执行，让 AI 真正「操作你的电脑」，而不是只聊天。
- 官网：https://www.aipyaipy.com
- 特点：本地执行、代码即代理、支持 MCP/Skills、跨平台（macOS / Windows / Linux）
---
## 场景
一位文创产品策划，需要为博物馆的「四羊方尊」做一份冰箱贴单品类文创提案。
**痛点**：
- **提案门槛高**：文创提案需要设计、文案、市场多专业协作，个人很难独立产出完整方案
- **文物易失真**：四羊方尊造型细节复杂，卷角羊首、扉棱、蕉叶纹稍有差错就会被专业人士吐槽
- **外包贵且慢**：找设计公司做单品类提案动辄数天数周，成本高、沟通反复
- **效果图难复用**：AI 生图缺少强制约束提示词，生成的文物形象五花八门、无法验收
**目标**：基于一张实拍照片，生成一份包含 4 种风格效果图、工艺定价、合规声明的完整文创提案。
---
## 操作步骤
1. 打开 AiPy，在集市安装 **「平面与设计（image2）」智能体** 与 **「网页前端开发」Skill**
2. 上传博物馆实拍的四羊方尊照片，输入提示词（见下方「提示词」）
3. AiPy 自动核对文物档案、提炼 F1–F10 特征约束、生成 4 种风格效果图、补齐工艺定价与合规声明
4. 对话式精调：随时说「换个风格」「定价改一下」，秒级响应修改
### 提示词
```text
根据我上传的在博物馆实拍的四羊方尊照片，做一份冰箱贴单品类文创提案：先核对文物权威档案信息，提炼不能失真的文物特征清单；再调用平面与设计智能体围绕同一件文物设计4种不同风格的冰箱贴方案（萌趣国宝、赛博青铜、水墨写意、极简浮雕），每种风格给出AI设计效果图和可复制的强制约束提示词；并把生成的图片嵌入对应的位置，再补充工艺、定价、市场定位和合规授权注意事项，做成一份精美的HTML提案页面。
```

## AiPy 实现过程
| 步骤 | 环节 | 说明 |
|------|------|------|
| 1 | 权威档案核对 | 联网核对四羊方尊文物档案：商代晚期、高 58.3cm、重约 34.5kg、1938 年出土于湖南宁乡、现藏中国国家博物馆 |
| 2 | 特征约束建模 | 提炼 F1–F10 文物特征强制约束清单（器类、题款、尺寸、轮廓、卷角羊首、蕉叶纹、扉棱、墨色五级等），确保 AI 生图不失真 |
| 3 | 四风格系列设计 | 围绕同一件文物输出萌趣国宝、赛博青铜、水墨写意、极简浮雕四种风格的 AI 效果图与可复制约束提示词，覆盖 29–99 元价格带 |
| 4 | 策略与合规收尾 | 补充单品类策略论证（高频场景、心智占位、收集闭环）、工艺与市场定位，并输出馆藏授权与专家复核合规声明 |
**技术栈**：Python、平面与设计（image2）智能体、网页前端开发 Skill、HTML/CSS

## 常见问题（FAQ）
**Q1：AiPy 需要联网吗？**
A：本案例需要联网核对文物权威档案信息，因此需要联网。AiPy 本身支持纯本地运行，数据不上传云端。
**Q2：需要会设计吗？**
A：不需要。用一句大白话描述文物与品类即可，AiPy 会自动完成设计、文案与排版。
**Q3：AiPy 支持哪些操作系统？**
A：支持 macOS / Windows / Linux 桌面端。
**Q4：生成的效果图能复现吗？**
A：可以。每张效果图都附带 F1–F10 强制约束提示词，复制即可复现同款设计。
**Q5：提案能直接用于商务沟通吗？**
A：可以。方案已包含工艺、定价、市场定位与合规授权声明，但正式量产前仍需馆藏方授权与专家复核。
