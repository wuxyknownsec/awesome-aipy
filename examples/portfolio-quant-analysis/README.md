# AiPy 实战：一句话完成持仓股深度量化分析（技术面 + 基本面 + HTML 报告）
> 把 4 只持仓股告诉 AiPy，自动完成数据获取、量化分析、图表绘制，输出一份可直接打开的响应式 HTML 分析报告。
**关键词**：AiPy、持仓量化分析、股票分析、技术面分析、基本面分析、数据可视化、HTML报告、投资决策、自然语言编程
---
## 什么是 AiPy？
AiPy（爱派）是由**北京知道创宇（Knownsec）**研发的开源 AI 桌面助手，核心理念是 **Python-Use**：
把自然语言直接翻译成 Python 代码并执行，让 AI 真正「操作你的电脑」，而不是只聊天。
- 官网：https://www.aipyaipy.com
- 特点：本地执行、代码即代理、支持 MCP/Skills、跨平台（macOS / Windows / Linux）
---
## 场景
某私募基金投资经理，需要定期对 4 只持仓股做深度分析并输出汇报报告。
**痛点**：
- **数据分散，难以全面掌握**：基本面数据、技术指标、新闻资讯散落在多个平台，反复切换查看
- **技术分析门槛高**：MACD、RSI、布林带、均线系统等技术指标需要专业知识才能解读
- **决策缺乏系统性**：面对多只持仓股票，缺乏统一的评估框架和决策矩阵，容易凭感觉操作
- **报告制作耗时费力**：定期汇报持仓情况，制作专业分析报告需要大量时间整理数据、绘制图表
- **情绪干扰判断**：面对市场波动，容易受贪婪和恐惧情绪影响，缺乏客观中立的分析视角
**目标**：输入 4 只持仓股，自动输出一份技术面 + 基本面双维度的量化分析报告。
---
## 操作步骤
1. 打开 AiPy，在集市安装智能体：**智能持仓助手**、**投资大师深度分析**、**网页前端开发**
2. 输入提示词（见下方「提示词」）
3. AiPy 自动获取数据、量化分析、生成 HTML 报告
### 提示词
```text
我有4只持仓股，请你结合量化算法+最新市场数据，从技术面+基本面双维度深度分析，给出明确操作建议，并生成简约商务风、响应式高颜值静态HTML分析报告，排版精致、数据可视化、逻辑严谨。
一、持仓明细
成都银行（成本15.259元）、三维通信（成本8.元）、首都在线（成本34.87元）、金风科技（成本8.51元）
二、个股分析要求
市场表现：近1年股价走势、涨跌幅、波动率、相对大盘强弱；
最新动态：近1个月公告、行业政策、机构评级，标注股价影响；
基本面：营收、净利润、市盈率、行业地位、核心业务、财务健康度、成长属性、风险点；
技术面：均线、支撑/压力位、成交量、MACD、KDJ、趋势判断；
操作结论：量化模型判定（增持/买入/持有/减仓/清仓）。
三、HTML报告硬性格式
布局：响应式，适配电脑、手机，商务简约配色；
顶部：持仓总览、成本、盈亏参考、综合评级；
必做模块：综合决策表（股票、操作建议、核心逻辑、动态影响、风险提示）；
个股板块：单股独立卡片，包含基本面、技术面、最新动态、操作依据；
排版：卡片布局、分级标题、高亮标注、简洁表格，无冗余内容。
四、输出要求
分析客观专业、结论明确不模糊，HTML成品可直接打开、数据可视化、重点突出。
```

## AiPy 实现过程
| 步骤 | 环节 | 说明 |
|------|------|------|
| 1 | 解析持仓信息 | 提取 4 只股票代码与持仓成本 |

| 6 | 输出 HTML 报告 | 响应式商务风，数据可视化，可直接打开 |

## 常见问题（FAQ）
**Q1：AiPy 需要联网吗？**
A：AiPy 本身支持纯本地运行，但本案例需要获取最新市场数据，因此需要联网抓取行情与资讯。
**Q2：需要会编程吗？**
A：不需要。用自然语言描述持仓和分析要求即可，AiPy 会自动生成并执行分析代码。
**Q3：AiPy 支持哪些操作系统？**
A：支持 macOS / Windows / Linux 桌面端。
**Q4：分析结论可以直接用于投资决策吗？**
A：不建议。本分析由 AI 基于历史数据和技术指标生成，不构成投资建议，请谨慎采纳。股市有风险，投资需谨慎。
**Q5：支持多少只持仓股？**
A：本案例分析了 4 只持仓股，数量可根据需求调整。
