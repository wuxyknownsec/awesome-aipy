# AiPy 实战：一句话生成 DJI Osmo Pocket 3 产品调研分析报告（单文件 HTML）
> 用一句大白话需求，让 AiPy 自动核实官网参数、汇聚三源口碑、生成 7 大模块报告，并配 4 张 AI 场景插图。
**关键词**：AiPy、产品调研、竞品分析、DJI Osmo Pocket 3、大疆口袋云台相机、HTML报告、数据分析、AI配图、自然语言编程
---
## 什么是 AiPy？
AiPy（爱派）是由**北京知道创宇（Knownsec）**研发的开源 AI 桌面助手，核心理念是 **Python-Use**：
把自然语言直接翻译成 Python 代码并执行，让 AI 真正「操作你的电脑」，而不是只聊天。
- 官网：https://www.aipyaipy.com
- 特点：本地执行、代码即代理、支持 MCP/Skills、跨平台（macOS / Windows / Linux）
---
## 场景
一位数码爱好者，想围绕「大疆 Osmo Pocket 3 口袋云台相机」做一份产品调研分析报告，面向普通消费者与内容创作者，帮助其判断是否值得购买。
**痛点**：
- **参数核对难**：官网、电商、评测文章各说一套，关键参数散落各处，逐项核对费时费力
- **口碑真假难辨**：软文与真实评价混杂，优缺点看不出哪些是普遍共识
- **决策没有抓手**：不知道适不适合自己，怕花了大几千买回来吃灰
**目标**：生成一份结构完整、来源可溯、结论分人的产品调研分析报告（单文件 HTML）。
---
## 操作步骤
1. 打开 AiPy，在集市安装 **「网页前端开发」Skill** 与 **「平面与广告设计」智能体**
2. 把任务提示词原样发给 AiPy（见下方「提示词」）
3. AiPy 自动抓取官网产品页核对参数，归纳媒体测评与用户口碑，按 7 大模块生成报告并配 4 张 AI 场景插图
4. 对话式精调：随时说「结论再犀利一点」「加一节价格对比」，秒级响应修改
### 提示词
```text
任务目标：围绕「大疆 Osmo Pocket 3 口袋云台相机」撰写一份产品调研分析报告，面向普通消费者与内容创作者，帮助其判断是否值得购买。
数据来源：使用公开可查的官方产品页、电商平台公开参数与用户评价、公开媒体报道与测评文章；不依赖任何本地私有文件或内部系统，若需示例数据请自行构造并注明为示例。
处理要求：报告需包含以下模块——①产品定位与核心卖点介绍；②功能亮点（如云台防抖、1英寸传感器、旋转触控屏、收音与续航等）；③优点与不足的客观对比（分条列出，避免夸大）；④适用人群与典型使用场景建议；⑤价格区间与购买渠道说明（仅列公开电商平台与官方商城，不出现具体账号或内部链接）；⑥与同价位竞品的简要横向对比表。所有信息需标注来源类型（官方/媒体/用户评价），对不确定信息注明「待核实」。
交付物：输出为单文件 HTML 页面，包含清晰的标题层级、对比表格与要点卡片式排版，配色统一、版式专业；封面与关键章节页（如亮点页、对比页、结论页）配主题相关的示意图或产品场景插图（可用 AI 生成或公开素材），其余页面以清晰排版呈现，避免大段纯文字堆砌；页面需适配桌面与移动端浏览。
```

## AiPy 实现过程
| 步骤 | 环节 | 说明 |
|------|------|------|
| 1 | 官网参数自动核实 | 抓取 DJI 官网产品页与参数页，逐项核对传感器、屏幕、续航、充电等硬指标 |
| 2 | 三源口碑汇聚 | 归纳公开媒体测评与电商/社区用户评价的普遍共识与分歧点，区分来源类型 |
| 3 | 报告结构化生成 | 按定位、亮点、优缺点、人群、价格、竞品、结论 7 大模块生成要点卡片与对比表 |
| 4 | 插图与双端排版 | 调用平面与广告设计智能体生成 4 张主题场景插图，输出暗色影棚风格、桌面移动端自适应的单文件 HTML |
**技术栈**：Python、网页前端开发 Skill、平面与广告设计智能体、HTML/CSS

## 常见问题（FAQ）
**Q1：AiPy 需要联网吗？**
A：本案例需要抓取公开的官网参数与媒体报道，因此需要联网。AiPy 本身支持纯本地运行，数据不上传云端。
**Q2：需要会编程吗？**
A：不需要。用一句大白话描述需求即可，AiPy 会自动完成调研、写作与排版。
**Q3：AiPy 支持哪些操作系统？**
A：支持 macOS / Windows / Linux 桌面端。
**Q4：报告可以修改吗？**
A：可以。用自然语言说「结论再犀利一点」「加一节价格对比」，AiPy 会秒级响应修改。
**Q5：报告能适配手机浏览吗？**
A：可以。输出的单文件 HTML 同时适配桌面与移动端。
