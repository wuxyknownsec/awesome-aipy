# AiPy in Action: Print a LAN PDF File with One Prompt (PowerShell + Printer Control)
> Just say "print c:\1.pdf with it", and AiPy scans the LAN printers, sets the default printer, and calls the system command to complete the print.
**Keywords**: AiPy, printer automation, LAN printer, PDF printing, PowerShell, office automation, batch printing, natural language programming
---
## What is AiPy?
AiPy is an open-source AI desktop assistant developed by **Knownsec**, built around the **Python-Use** philosophy:
it translates natural language directly into Python code and executes it, so AI truly "operates your computer" instead of just chatting.
- Website: https://www.aipyaipy.com
- Highlights: local execution, code as agent, MCP/Skills support, cross-platform (macOS / Windows / Linux)
---
## Scenario
An office worker needs to print a PDF file on a printer within the local area network.
**Pain Points**:
- **Unclear about the printer IP and name**: how to find a printer on the LAN? What should the network path look like?
- **Driver installation is a hassle**: switching to another computer means reinstalling drivers, and you get stuck when IT is away
- **PDF printing gets garbled**: dragging the file in often leads to missing fonts and distorted layout
- **No scripting for batch printing**: clicking the "Print" button for dozens of files one by one is terribly inefficient
**Goal**: Have AiPy find the printer and successfully print the PDF with a single prompt.
---
## Steps
1. Open AiPy and install the agent **Printer Control** from the marketplace
2. Upload the file to print and enter the prompt (see "Prompt" below)
3. AiPy scans the LAN, sets the default printer, and calls the system command to complete the print
### Prompt
```text
There is a printer on the local network. Please help me print c:\1.pdf with it.
```
---
## Core Commands Generated by AiPy
```
# Scan the LAN and discover available printers
Get-Printer | Select-Object Name, DriverName, PortName
# Set the default printer (using the discovered printer name)
(New-Object -ComObject WScript.Network).SetDefaultPrinter("\\192.168.x.x\PrinterName")
# Call the system command to print the PDF
Start-Process -FilePath "c:\1.pdf" -Verb Print -Wait
```

## How AiPy Did It
| Step | Stage | Description |
|------|-------|-------------|
| 1 | Scan LAN printers | Use PowerShell to list available printers and their port information |
| 2 | Identify the target printer | Choose the appropriate printer for the network environment |
| 3 | Set as default printer | Temporarily set the selected printer as default via WScript.Network |
| 4 | Call the system print command | Use Start-Process -Verb Print to print the PDF directly, preserving the full format |
| 5 | Confirm completion | Wait for the print queue to clear and output the execution result |
**Tech Stack**: PowerShell, WScript.Network COM object, Start-Process

## FAQ
**Q1: Does AiPy require an internet connection?**
A: No external network is needed. AiPy runs fully locally, and this case only operates printers within the LAN, so data never leaves the intranet.
**Q2: Do I need to know how to code?**
A: No. Just state your printing need in plain language, and AiPy generates and runs the PowerShell commands automatically.
**Q3: Which operating systems does AiPy support?**
A: The AiPy application supports macOS / Windows / Linux, while this case's printing script is based on Windows PowerShell and requires a Windows environment.
**Q4: Can it print in batches?**
A: Yes. Just say "print every PDF in this folder", and AiPy loops through them automatically.
**Q5: What if no printer is found?**
A: AiPy first runs Get-Printer to scan available devices. If the list is empty, make sure the printer is powered on and connected to the same LAN.
