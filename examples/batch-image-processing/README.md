批量图片处理自动化示例
一句话让 AiPy 批量完成加水印、压缩、重命名、格式转换，全程无需盯屏。

场景
一位有 5 年摄龄的摄影爱好者，每次外拍回来都要处理大量照片，痛点很集中：

RAW 格式转换：相机文件体积大，需逐张导出 JPG 调参
批量加版权水印：用 PS 逐张加水印防盗用，处理几十张极耗时
压缩优化：原始照片几 MB 到几十 MB，需压缩以适应平台限制
素材整理混乱：相机自动命名无意义，手动重命名繁琐
目标：把 50 张照片一次性完成「加水印 + 压缩 + 重命名 + 转 PNG」。
操作步骤
打开 AiPy，在集市安装智能体：平面与广告设计（image2）
上传需要处理的图片，输入提示词（见下方「原始提示词」）
AiPy 自动生成 Python 代码并执行，全程无需盯屏
原始提示词
AiPy 自动干活过程
步骤	环节	说明
1	批量添加 "aipy" 水印	位置精准，防止盗用
2	自动压缩照片体积	画质清晰且体积可控
3	按规则批量重命名	按「松鼠-N」规则，文件管理更清晰
4	一键转换 PNG 格式	兼容性好，画质无损
